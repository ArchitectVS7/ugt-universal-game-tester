# Integrations index

Every entry below is a self-contained trial-ladder run of UGT against a real game: `HANDOFF.md`
(resume-here doorway), `README.md` (how it works / how to run), `RESULTS.md` (commit-traceable findings
log), plus the ladder scripts themselves (`spike_*.py` → `smoke_*.py` → `verify_round1.py` (R1
playability) → `verify_round2.py` (R2 full content spine) → `verify_round3.py` (R3 exploit-hunter +
same-seed replay determinism)). Every adapter drives the **real running game** — a live server, a real
browser, or the game's own subprocess harness — never a re-implementation of its logic. See root
`PLAN-FORWARD.md` for why that rule is load-bearing here.

Ladder rungs above R1 are optional gates a game can still be mid-ladder on; "FULL LADDER COMPLETE" means
every rung through R3 is green. The LLM playtest tier (`ugt playtest` / a direct `playtest_<game>.py`
driver) is a separate, later tier layered on top once the ladder is green, and is tracked per-game below.

## Notes for readers

- `spacerquest` and `spacerquest_old` share a name but are **unrelated**: `spacerquest` is a from-scratch
  restart against a new design ("Rimward"); `spacerquest_old` is the retired original, archived on hold.
  Each one's README says this explicitly — don't conflate them.
- `warzones`' R3 script is named `verify_round10.py`, not `verify_round3.py` — a historical naming quirk,
  not a missing file.
- Every game folder's `HANDOFF.md`/`RESULTS.md` are the living source of truth; this table is a snapshot —
  check the per-game docs for anything newer.
